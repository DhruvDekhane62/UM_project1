# UK Top 50 Playlist Analysis

Unified Mentor Project One. Market structure, artist diversity and content analysis of the UK Top 50 playlist for Atlantic Recording Corporation.

## Setup
```
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
Place the dataset at `data/raw/uk_top50.csv`, open this folder in Antigravity, and follow `prompts/00_kickoff.md`.
